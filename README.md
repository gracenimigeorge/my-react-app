# Student Management Portal

A web application for managing student records, built with React on the front end and PostgreSQL as the database. The project was developed with the help of Antigravity AI.

**Live demo (front end):** https://gracenimigeorge.github.io/my-react-app/

## Tech Stack

- **Front end:** React, Vite, Tailwind CSS
- **Database:** PostgreSQL
- **Deployment:** GitHub Pages (front end only)

## Features

- Add, view, edit and delete student records
- Clean, responsive interface
- Student data stored in a PostgreSQL database

## Run Locally

1. Clone the repository

       git clone https://github.com/gracenimigeorge/my-react-app.git
       cd my-react-app

2. Install dependencies

       npm install

3. Start the development server

       npm run dev

4. Open http://localhost:5173 in your browser

## Database

The app expects a running PostgreSQL database. Set it up locally before starting the app, and make sure the connection settings match your local setup.

## Note

The live demo hosts only the React front end. Features that need the PostgreSQL database work only when the database and its back end are running locally.
